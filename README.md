# fedimint_floresta
A Bitcoin backend that lets a Fedimint guardian run on Floresta, a lightweight Utreexo node, instead of bitcoind. It lets communities run a complete, self-validating Bitcoin and ecash stack on low-cost hardware, lowering the cost of self-custody.
